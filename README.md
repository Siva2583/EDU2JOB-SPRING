# EDU2JOB

An AI-powered career recommendation platform that predicts suitable job roles and career paths based on user education, academic performance, and technical skills.

---
##Live Demo


https://github.com/user-attachments/assets/b62605c9-e3de-4630-8412-d9ed3c461f32



## Features

* Predicts suitable job roles using a Machine Learning recommendation system
* Career suggestions based on education, CGPA, and skills
* Secure user authentication and role-based access using JWT
* User registration and login system
* Optimized ML pipeline with feature engineering and preprocessing
* Interactive full-stack web interface

---

## Machine Learning Model Details

### Algorithm

* Random Forest Classifier

### Input Features

* Education Qualification
* Technical Skills
* Academic Performance (CGPA)
* User Interests

### Predicted Outputs

* Suitable Industries
* Recommended Job Roles
* Career Path Suggestions
